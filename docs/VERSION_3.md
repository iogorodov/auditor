# Версия 3 — PWA, сборка, CI и деплой

Превращает приложение в устанавливаемую офлайн-PWA и настраивает автоматический деплой.
Опирается на Версии 1–2. До этой версии всё работает только на `http://localhost`.

## Прод-сборка (Bun)

Два выхода сборки:

| Entry point | Выход | Опции |
|---|---|---|
| `index.html` (тянет `src/app.ts`) | `app.[hash].js` + `app.[hash].css` | формат **iife**, хэши, минификация |
| `src/sw.ts` | `sw.js` | **без хэша**, фиксированное имя, target = worker |

- `app.js` — единый iife-бандл (без code-splitting). Файлы с хэшами иммутабельны, кэшируются надолго.
- `sw.js` — стабильное имя: регистрируется по фиксированному URL и обновляется браузером по побайтовому
  сравнению. Отдаётся с `Cache-Control: no-cache`.
- **Список пред-кэша** для Service Worker генерируется из результата сборки (имена `app.[hash].*`).

```
dist/
  index.html
  app.[hash].js
  app.[hash].css
  sw.js
  manifest.webmanifest
  icons/…
```

## PWA

Три части офлайн-механики:

- **Web App Manifest** (`manifest.webmanifest`) — имя, иконки, `display: standalone`, стартовый URL, тема.
  Даёт установку на телефон и запуск как нативного приложения.
- **Service Worker** (`sw.js`) — при установке кэширует оболочку (`app.[hash].js/css`, иконки), затем отдаёт из
  кэша → приложение открывается **без сети**. **CSV каталога не кэширует** (тянется по «Обновить каталог» в
  IndexedDB). Регистрируется из `app.ts`: `navigator.serviceWorker.register('/sw.js')`.
- **IndexedDB** — данные аудитов и кэш каталога (уже с Версии 1).

Цепочка обновления: правка кода → меняется `app.[hash].js` → меняется список пред-кэша внутри `sw.js` →
меняются байты `sw.js` → браузер видит новый Service Worker → перекэширует оболочку.

## Инфраструктура

- **Хостинг:** статический — GitHub Pages / Netlify / Cloudflare Pages. Бэкенда нет.
- **HTTPS обязателен** в проде (Service Worker и установка PWA работают только в безопасном контексте;
  исключение — `localhost`).
- **GitHub Actions:** на push — `bun install` → `bun test` → `bun build` → деплой `dist/` на выбранный хост.

## Проверка

- **Офлайн-прогон:** собрать прод-бандл, открыть по HTTPS, включить авиарежим, перезагрузить — приложение
  открывается; данные из IndexedDB на месте.
- **Установка на телефон** (Add to Home Screen) и запуск в standalone.
- **E2E (Playwright):** офлайн-сценарий (Service Worker) + персист после перезагрузки.
- CI зелёный: тесты + сборка + деплой.
